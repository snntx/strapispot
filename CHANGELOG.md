# Changelog

## 0.1.0

First release.

- Command palette opened with Cmd/Ctrl + Shift + K on any admin page.
- Ranked search across all collection types you can read, with highlighted matches and a snippet when the match is not in the title.
- `in <collection> <text>` searches inside one collection, with Tab completion.
- `new` lists the collections you may create in, with their relations, and opens the create screen.
- Commands are plain keywords; a leading `/` is optional.
- Permission-aware: collections you cannot read or create in are skipped or greyed out with a reason.
- Settings page (Settings → Strapispot): default shortcut, a per-browser shortcut, which collections are searchable, and the title field per collection.
- New role permission: Strapispot → Change settings.
- Light and dark mode; works in a narrow window.
